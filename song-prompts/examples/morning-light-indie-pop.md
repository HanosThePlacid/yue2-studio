# Morning Light — Indie Pop (example)

Example preset. Every `.md` file under `song-prompts/` with a **Style prompt:** block is
imported as a preset on startup. Planning mode = off. Target length ~ 90 s.

**Style prompt:**

```
English, indie pop, 110 BPM, bright acoustic guitar, soft drums, warm bass, warm female lead vocal, uplifting, polished demo mix
```

**Lyrics:**

```
[Verse]
Soft morning light is touching the window,
I hear the city waking below.
Coffee and quiet, the radio humming,
Something is changing, I already know.

[Chorus]
Stay with the rhythm, let it carry us home,
Sing with the sunrise, we are never alone.
Stay with the rhythm, let it carry us home,
Sing with the sunrise, we are never alone.

[Outro]
Never alone.
```
